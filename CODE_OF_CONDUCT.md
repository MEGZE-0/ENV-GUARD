# Code of Conduct

## Our standard

We want ComposeEnvGuard to be a welcoming project for people of every background and experience level. Be respectful and constructive. Assume good intent, critique ideas rather than people, and help newcomers.

Examples of behaviour that helps: clear bug reports, patient review comments, documentation fixes, and thanks for good work.

Examples of behaviour that is not acceptable: harassment, insults, discrimination, publishing others' private information, and deliberately disruptive or spam activity.

## Scope

This code applies to project spaces (issues, pull requests, discussions, and any community channels the maintainers run) and to public spaces where someone represents the project.

## Reporting

Report concerns to the maintainers privately through the contact details on the repository profile, or through GitHub's report option on a comment. Reports are handled confidentially. The maintainers will review each report and decide on an appropriate response, which may range from a private warning to removal from the project.

## Attribution

This code of conduct is a short, plain-language statement written for this project. It is not a copy of an external template.
