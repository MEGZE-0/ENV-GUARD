# ComposeEnvGuard v0.1.0

**Status: pre-release draft.** Do not publish this description until the release gates in [docs/publishing.md](../publishing.md) are met. The repository must also be public before the links and the GitHub Action reference below work for other people.

## What it is

ComposeEnvGuard is a read-only, local checker for Docker Compose environment configuration. It reads your `compose.yaml` and your `.env.example` (or `.env.sample`), then reports:

- variables that Compose uses but the template does not document (CEG001),
- duplicate template entries (CEG002),
- required `env_file` entries that do not exist (CEG003),
- documented variables that nothing references (CEG004),
- invalid or unsupported configuration (CEG005),
- contract mismatches for services you declare in `.composeguard.yaml` (CEG006),
- env files that were not read, so their contents are unverified (CEG007),
- suspicious environment mappings (CEG008).

It never prints environment values, never reads `.env` files by default, never runs your containers or your code, and makes no network calls during a scan.

## Supported platforms

| Platform | Status for v0.1.0 |
| --- | --- |
| Python 3.11, 3.12, 3.13 on Linux (Ubuntu 24.04 in CI) | **Supported.** Tested in CI on every commit. |
| Docker image (Linux containers) | **Supported.** Built and smoke-tested in CI on a Docker daemon. |
| GitHub Actions on `ubuntu-24.04` runners | **Supported.** The composite action is tested in CI. |
| macOS (Python commands and Docker Desktop) | **Not tested.** The commands are standard, but they have not been run on macOS. |
| Windows (PowerShell commands, Docker Desktop, Windows runners) | **Not tested.** The PowerShell commands are written but have not been run on Windows. |
| Python 3.10 and older | **Not supported.** The package requires Python 3.11 or newer. |
| Installation from PyPI | **Not available.** The package is not published. Install from a clone of the repository. |

If you try the macOS or Windows commands and they work or fail, please open an issue and say which version you used. This helps us move these platforms from "not tested" to "tested".

## Ways to run it

- **Command line:** `composeguard scan .` (exit 0 pass, 1 threshold met, 2 bad input or execution error).
- **Docker:** `docker run --rm -v "$PWD:/workspace:ro" compose-env-guard scan /workspace`.
- **HTTP API (local only):** `composeguard serve` (requires the `api` extra) or `docker compose up --build -d`. Both bind to `127.0.0.1`. The API has **no authentication**.
- **GitHub Action:** `MEGZE-0/ENV-GUARD@v0.1.0`. It writes a Markdown report to the job summary and needs no secrets or write permissions.

## Known limitations

Full details are in [docs/limitations.md](../limitations.md). The ones that matter most:

- **Runtime is not checked.** A variable missing from the template is a warning ("not documented"), not proof that it is missing at runtime. Your shell, CI secrets or an unread file may supply it.
- **Compose semantics are partial.** Override files are merged as a union of declarations, not by Compose's merge rules. `extends`, `include` and custom tags such as `!reset` are reported but not resolved.
- **No full schema validation.** Use `docker compose config` for that.
- **Discovery is not recursive.** The default file names are looked for only in the project directory. Other Compose files must be passed explicitly with `--compose`.
- **The API is local-only by design.** It has no authentication, rate limiting or TLS. Do not expose it publicly without a proxy that adds those controls.
- **Variable names appear in reports.** Names such as `ADMIN_PASSWORD` are shown by design. Values are never shown.
- **The Docker base image is pinned by tag, not digest.** Pin a digest before production use.

## Security notes

- The scanner never executes code from your project. YAML is parsed with `SafeLoader` and unsupported tags are reported, not built.
- Paths that escape the project (traversal, absolute paths, symlinks) are refused.
- Reports and error messages never contain environment values. See [SECURITY.md](../../SECURITY.md) for the threat model and the review performed for this release.

## Install (from a clone, until the repository is public and PyPI publication exists)

Requires Python 3.11 or newer.

```bash

cd ENV-GUARD
python -m pip install .
composeguard scan examples/healthy-project
```
