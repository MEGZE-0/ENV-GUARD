# ComposeEnvGuard v0.1.0

**Status: pre-release.** This document is the draft release description. It must not be published until the release gates in [docs/publishing.md](../publishing.md) are met.

## What it is

ComposeEnvGuard is a read-only, local checker for Docker Compose environment configuration. It reads your `compose.yaml` and your `.env.example` (or `.env.sample`), then reports:

- variables that Compose uses but the template does not document (CEG001),
- duplicate template entries (CEG002),
- required `env_file` entries that do not exist (CEG003),
- documented variables that nothing references (CEG004),
- invalid or unsupported configuration (CEG005),
- contract mismatches for services you declare in `.composeguard.yaml` (CEG006),
- env files that were not read, so their contents are unverified (CEG007),
- suspicious environment mappings (CEG008).

It never prints environment values, never reads `.env` files by default, never runs your containers, and sends nothing over the network.

## Ways to run it

- **Command line:** `composeguard scan .` (exit 0 pass, 1 threshold met, 2 bad input).
- **Docker:** `docker run --rm -v "$PWD:/workspace:ro" compose-env-guard scan /workspace`.
- **HTTP API (local):** `composeguard serve` or `docker compose up --build -d`, bound to `127.0.0.1`. It has no authentication.
- **GitHub Action:** composite action in `action.yml`, which writes a Markdown report to the job summary.

## Verified for this release

Verified on the release-candidate commit through GitHub Actions and local runs:

- Unit and integration tests: 262 passed, 2 Docker tests skipped locally. In CI the Docker tests run on a daemon.
- Lint (`ruff check`, `ruff format --check`) and coverage (94.75%, gate 85%).
- Package build and a clean-venv wheel install; a fresh clone installs and passes the same tests.
- Docker in CI: image build, non-root uid 10001, healthy example exit 0, broken example exit 1 with CEG001–CEG004, `docker compose up`, `/health`, `/docs`, `POST /api/v1/scan`, traversal rejected with 422, port published on `127.0.0.1` only.
- The composite action runs against the healthy example in CI.
- Secret-leakage regression tests (planted values never appear in any output channel).

## Not verified for this release

- Windows and macOS (no runs of the commands on those systems).
- The composite action from another repository (`MEGZE-0/ENV-GUARD@v1` does not exist until a tag is published).
- Installation from PyPI (the package is not published).
- Docker on a machine other than the CI runner.

## Known limitations

See [docs/limitations.md](../limitations.md). The most important:

- It cannot tell whether a variable is set at runtime; "not documented" is a warning, not proof of a runtime failure.
- Compose override merging, `extends`, and `include` are not resolved.
- Compose schema validation is not performed.
- The API has no authentication, rate limiting, or TLS.

## Install (from a clone, until PyPI publication)

cd ENV-GUARD
